# README for the judges (needs Biggie: README.md is lead-only)

Issue #47 asked for a review of the repo README as the project page. Findings, in order of importance:

1. **The repo must be public at submission.** The README says it is private until then; the challenge requires the
   code to be public and open. Someone with owner rights has to switch it, and the line must go when it does.
2. **The README is written for contributors, not judges.** A judge lands on "Start (everyone)": install Rust, say "I'm
   Biggie". Put a short section above it: what it is (the two sentences of the idea), a link to the live app and the
   demo, how to run it in one command, what NASA data it uses, and the "what we do not claim" list.
3. **Say how AI agents were used**, in a sentence, because `AGENTS.md` is the first thing a judge opens.
4. **Add the final project name** when the team chooses one; `firecal` is a working name.
5. **Add a screenshot of the calendar** once there is one (Eminem can supply it; a JPG or PNG under 10 MB).
